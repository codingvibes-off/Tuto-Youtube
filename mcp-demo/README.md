# mcp-demo

Projet de démo pour montrer le branchement d'un MCP sur Claude Code
(GitHub + Gmail), en direct.

## Avant l'enregistrement

### 1. GitHub
1. Crée un token: github.com -> Settings -> Developer settings ->
   Personal access tokens (scope minimum: repo)
2. Remplace `TON_TOKEN_GITHUB_ICI` dans `.mcp.json`
